Dans l'unification jauge-Higgs dynamique dans l'espace-temps déformé de Randall-Sundrum, où le champ de Higgs 4D est unifié avec les champs de jauge et où la symétrie électrofaible est brisée dynamiquement par le mécanisme de Hosotani, les couplages trilinéaires WWZ, WWH et ZZH, où H désigne le champ de Higgs, sont évalués. Les deux derniers couplages sont supprimés d'un facteur \cos θ_H où θ_H est la phase d'Aharonov-Bohm de Yang-Mills dans la dimension supplémentaire, tandis que les couplages WWZ restent les mêmes que dans le modèle standard avec une bonne précision.
