L'effet Casimir est étudié dans des nanotubes de carbone cylindriques et toroïdaux dans le cadre du modèle de type Dirac pour les états électroniques. L'énergie de Casimir topologique est positive pour les nanotubes cylindriques métalliques et négative pour les semi-conducteurs. La compactification toroïdale d'un nanotube cylindrique le long de son axe augmente l'énergie de Casimir pour des conditions aux limites de type métallique (périodiques) le long de son axe et diminue l'énergie de Casimir pour les compactifications de type semi-conducteur. Pour des nanotubes métalliques de longueur finie, les forces de Casimir agissant sur les bords du tube sont toujours attractives, tandis que pour ceux de type semi-conducteur elles sont attractives pour de petites longueurs du nanotube et répulsives pour de grandes longueurs.
