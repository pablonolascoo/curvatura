Este informe reúne cuatro estudios de caso de proyectos de atención integrada en distintos países, para mostrar cómo funciona la integración en la práctica. Su objetivo es proponer una estructura de recomendaciones sobre lo que hace falta para que la integración tenga éxito, y define unos ingredientes clave para avanzar a partir de cuatro programas reales. Es un trabajo de política sanitaria, ajeno a la física.
