Nous montrons qu'un champ scalaire {\it sans masse} dans un fond d'ondes gravitationnelles peut développer une valeur moyenne dans le vide non nulle. Nous établissons des comparaisons avec la génération d'une valeur moyenne dans le vide non nulle pour un champ scalaire dans le mécanisme de Higgs et avec le vide de Casimir dynamique. Nous proposons que cette valeur moyenne dans le vide, engendrée par une onde gravitationnelle, puisse être reliée à la production de particules par des ondes gravitationnelles et puisse avoir des conséquences pour l'Univers primordial, où les champs scalaires sont censés jouer un rôle important.
