Las detecciones de baja latencia de ondas gravitacionales (GWs) son cruciales para permitir observaciones de seguimiento rápidas de transitorios astrofísicos con telescopios convencionales. Hemos desarrollado un pipeline de baja latencia que usa una técnica llamada filtrado de Respuesta al Impulso Infinita Paralela Sumada (SPIIR), implementada en una Unidad de Procesamiento Gráfico (GPU). En este artículo explotamos la nueva arquitectura de acceso a memoria \textit{Maxwell} de las GPU de NVIDIA, en concreto las técnicas de caché de datos de solo lectura, warp-shuffle y operaciones atómicas entre warps. Obtenemos una aceleración de 3 veces respecto a nuestra implementación anterior de esta técnica de filtrado. Para abordar SPIIR con relativamente pocos filtros, desarrollamos una nueva configuración de hilos de GPU con una aceleración de casi 10 veces. Además, implementamos un esquema multitasa de filtrado SPIIR usando GPU Maxwell. Logramos una aceleración de más de 100 veces respecto a una CPU de un solo núcleo para el esquema de filtrado multitasa. Esto da como resultado una reducción global del uso de CPU de 21 veces para todo el pipeline SPIIR.
