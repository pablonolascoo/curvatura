Nous examinons la possibilité de solutions statiques de trou de ver dans la théorie de Brans-Dicke dans le vide, tant dans le repère original (de Jordan) que dans le repère reéchelonné conformément (d'Einstein). Il s'avère que, dans le premier, les trous de ver n'existent que dans un intervalle très étroit du paramètre de couplage, à savoir -3/2<omega<-4/3. Il est montré que ces trous de ver ne sont pas traversables en pratique. Dans le second repère, il n'existe aucune solution de trou de ver à moins de violer à la main les conditions d'énergie.
