El problema de dispersión inversa se aplica a ecuaciones en derivadas parciales bidimensionales llamadas ecuaciones de solitones, como la ecuación KdV y otras. También se utiliza para integrar las ecuaciones de Einstein con simetría axial. Estos problemas de dispersión inversa parecen distintos. Mostramos que pueden entenderse de forma unificada. Como aplicación a la ecuación de Einstein, encontramos soluciones de las ecuaciones de Einstein-Maxwell con carga magnética.
