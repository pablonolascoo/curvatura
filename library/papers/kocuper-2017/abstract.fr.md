Pour être traversable, le trou de ver lorentzien statique doit être constitué d'une matière exotique qui viole la condition d'énergie faible. Les champs quantifiés sont les candidats naturels, car leur tenseur énergie-impulsion possède, dans de nombreux cas, les propriétés souhaitées. Dans cet article, nous construisons et examinons le tenseur énergie-impulsion des champs quantifiés massifs scalaire, spinoriel et vectoriel dans six espaces-temps de trou de ver statiques. Nous trouvons que, dans tous les cas considérés, les champs quantiques violent les conditions de Morris-Thorne et n'ont pas la forme nécessaire pour soutenir la gorge du trou de ver. Cela concorde avec les résultats antérieurs et indique que les champs quantiques massifs rendent les trous de ver moins opérants.
