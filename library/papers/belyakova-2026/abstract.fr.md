Pour assurer l'annulation des anomalies, les extensions $U(1)$ inspirées de $E_6$ du modèle standard supersymétrique (SUSY) minimal (MSSM) font intervenir de la matière exotique supplémentaire. Le neutralino exotique le plus léger de ces modèles peut être stable et contribuer à la densité de matière noire froide. Nous considérons les interactions d'un tel neutralino avec les nucléons dans une extension spécifique du MSSM avec une symétrie de jauge $U(1)_N$ supplémentaire (SE$_6$SSM). Les contraintes sur les couplages de cet état, fixées par les bornes expérimentales actuelles issues des expériences de détection directe, sont examinées. Les résultats obtenus peuvent être généralisés à d'autres modèles SUSY inspirés de $E_6$ avec une symétrie de jauge $U(1)$ supplémentaire.
