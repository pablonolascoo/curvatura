Nous mettons en place une approche par effet tunnel de l'effet Hawking analogue dans le cas de modèles de gravité analogue affectés par des effets dispersifs. Une équation effective de type Schroedinger pour le phénomène de diffusion de base IN->P+N*, où IN est le mode incident, P le mode réfléchi de norme positive et N* celui de norme négative, signalant la création de particules, est dérivée en vue d'une description approchée du phénomène. Les horizons et la pénétration de barrière jouent manifestement un rôle clé dans la création de paires. La limite non dispersive est également retrouvée correctement. Les inconvénients du modèle sont aussi soulignés et une solution ad hoc possible est suggérée.
