Este trabajo estudia la eficacia de los agujeros negros acústicos para generar ondas viajeras no reflejadas de banda ancha utilizando una única fuente de excitación. Se inspira en observaciones similares en la membrana basilar del oído interno de los mamíferos. Una viga de aluminio se mecaniza para introducir un estrechamiento gradual y asimétrico según una ley de potencias en uno de sus extremos. Este extremo estrechado se cubrió después parcialmente con cinta viscoelástica para potenciar el efecto de agujero negro acústico en el sistema. Este montaje se utiliza a continuación para validar un modelo desarrollado a partir de la teoría de vigas de Euler-Bernoulli. Tras obtener un buen acuerdo entre el modelo y el montaje experimental en un amplio rango de frecuencias de excitación (1 kHz a 10 kHz), el modelo se utiliza para realizar un estudio paramétrico que investiga los efectos de distintas variables sobre la respuesta del sistema. Este estudio puso de manifiesto la eficacia de los agujeros negros acústicos para sostener ondas viajeras en un amplio rango de frecuencias. Optimizando parámetros como el orden de la ley de potencias, puede potenciarse significativamente este efecto. Esto resulta especialmente apreciable hacia el extremo de bajas frecuencias.
