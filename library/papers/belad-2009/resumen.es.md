Se propone una técnica para etiquetar lógicamente los elementos de imágenes de documentos, como títulos o párrafos, mediante árboles de decisión. El sistema usa un OCR para obtener rasgos físicos de cada bloque de texto y aplica el algoritmo CHAID mejorado, al que se añaden reglas lógicas extraídas del conocimiento de maquetación. Se prueban dos configuraciones, un árbol por elemento y un único árbol para todos, sobre unos 1000 documentos de congresos, con una tasa de error inferior al 6 por ciento para nueve etiquetas. No guarda relación con la física ni con la propulsión.
