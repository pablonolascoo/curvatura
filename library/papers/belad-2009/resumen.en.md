A technique is proposed for logically labelling the elements of document images, such as titles or paragraphs, using decision trees. The system uses OCR to obtain physical features of each text block and applies an improved CHAID algorithm, to which logical rules drawn from layout knowledge are added. Two setups are tested, one tree per element and a single tree for all, on about 1000 conference documents, with an error rate below 6 percent across nine labels. It has no connection to physics or propulsion.
