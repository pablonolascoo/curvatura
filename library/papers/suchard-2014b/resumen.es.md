El trabajo busca un modelo de materia que explique la electrogravedad. Mide cuánto se aparta una partícula de prueba de una geodésica mediante su aceleración no geodésica y, para prescindir de trayectorias concretas, introduce un campo escalar de curvatura basado en una nueva noción de tiempo. Ese tiempo es el máximo tiempo propio medible desde cada evento hasta la singularidad inicial, no observable localmente, pero cuyo gradiente sí es local. Si varias curvas cruzan un mismo evento, el gradiente no es paralelo a sí mismo, lo que define un campo de curvatura. Esto lleva a un formalismo que sustituiría al tensor energía-impulso convencional, para física clásica y cuántica, y a una teoría de electrogravedad.
