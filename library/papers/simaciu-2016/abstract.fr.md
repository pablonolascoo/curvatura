Le présent article vise à compléter un article antérieur où le monde acoustique a été introduit. Pour cela, on analyse les interactions qui se produisent entre les inhomogénéités du milieu acoustique, induites par les vibrations acoustiques se propageant dans le milieu. Lorsqu'un paquet d'ondes se propage dans un milieu, le milieu devient inhomogène. Le paquet d'ondes sphérique se comporte comme une lentille sphérique acoustique pour les ondes planes acoustiques. Selon le principe de causalité, il existe une interaction entre l'onde et le paquet d'ondes planes. Dans des conditions spécifiques, le paquet d'ondes se comporte comme un trou noir acoustique.
