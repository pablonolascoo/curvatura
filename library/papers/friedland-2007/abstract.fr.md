Dans une classe de modèles à dimensions supplémentaires avec une métrique tordue et une seule brane, le photon peut être localisé sur la brane par la seule gravité. Une caractéristique intrigante de ces modèles est la possibilité que le photon s'échappe dans les dimensions supplémentaires. La recherche de cet effet a motivé la série actuelle d'expériences de précision sur la désintégration de l'orthopositronium. Nous faisons remarquer que dans ce cadre un photon dans un plasma devrait être métastable. Nous considérons les conséquences astrophysiques de cette observation, en particulier ce qu'elle implique pour le taux de désintégration des plasmons dans les étoiles des amas globulaires et pour le taux de refroidissement des supernovae à effondrement de cœur. Les bornes résultantes sur le paramètre du modèle dépassent de nombreux ordres de grandeur la portée possible des expériences sur l'orthopositronium.
