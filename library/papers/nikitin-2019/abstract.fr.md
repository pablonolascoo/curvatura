Dans cet article, nous continuerons à étudier le modèle de trous noirs couplés à des flux radiaux de matière noire (étoiles RDM). Selon des études récentes, ce modèle décrit bien les courbes de rotation (RC) expérimentales des galaxies spirales et, de plus, les étoiles RDM peuvent produire des signaux ayant les caractéristiques des sursauts radio rapides (FRB). Dans cet article, nous effectuerons une analyse combinée de données expérimentales de RC et de FRB, ce qui permettra de contraindre plus étroitement les paramètres du modèle. Nous montrerons aussi que, dans le cadre du modèle, la relation de Tully-Fisher de pente $ β= 3-4 $ peut être obtenue. Ensuite, plusieurs solutions particulières seront considérées : le four tachyonique, solution dans laquelle le flux entrant de tachyons se transforme en un flux sortant de particules massives ; le condensat de coque, une singularité nue de masse négative recouverte d'une coque mince de masse positive, de sorte que la solution de Schwarzschild de masse négative à l'intérieur se raccorde à une solution de masse positive à l'extérieur ; ainsi qu'une solution RDM avec constante cosmologique. De plus, dans le modèle considéré, des diagrammes de Penrose seront construits, qui partagent des traits communs avec les solutions de Schwarzschild de masse positive et négative, dont le modèle est la combinaison. Le mécanisme de formation effective de masses négatives dans le modèle est discuté ; il s'active lorsque la densité du noyau central dépasse la valeur de Planck, de façon similaire à l'effet de rebond quantique étudié précédemment.
