Repasamos resultados recientes sobre el entrelazamiento en campos cuánticos en espaciotiempos cosmológicos y fenómenos relacionados en el espaciotiempo plano, como el efecto Unruh. Empezamos con un resumen de resultados importantes sobre el entrelazamiento de campos y la matemática de las transformaciones de Bogoliubov que se usa muy a menudo para describirlo. Después discutimos el modelo de detector de Unruh-DeWitt, un modelo útil de detector local genérico de partículas. Este modelo de detector se ha utilizado con éxito como herramienta para obtener muchos resultados importantes. En este contexto discutimos dos tipos concretos de estos detectores: un qubit y un oscilador armónico. Recientemente se ha mostrado que este último tiene aplicaciones importantes cuando se quiere sondear la física no perturbativa de detectores que interactúan con campos cuánticos. Detallamos después varios avances recientes en el estudio y la aplicación de estas ideas, entre ellos los ecos del universo primitivo, la cosecha de entrelazamiento y una propuesta incipiente de sismología cuántica.
