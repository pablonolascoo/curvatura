Le livre soutient que le voyage dans le temps est métaphysiquement possible et qu'aucun des arguments contre lui n'est solide. Il se concentre sur le paradoxe du grand-père : selon l'auteur, un voyageur vers le passé aurait la capacité de tuer son grand-père sans jamais le faire. Il explore ensuite les conséquences pour les probabilités et la théorie de la décision. Il termine sur les dangers du voyage dans le temps et sur l'intérêt d'empêcher tout objet de voyager dans le temps. C'est une analyse philosophique, non physique.
