La métrique acoustique analogue a été initialement dérivée pour des perturbations acoustiques adiabatiques se propageant dans un fluide parfait isentropique et irrotationnel. Dans le cadre d'une description hydrodynamique lagrangienne, nous démontrons que, sous certaines conditions, la métrique acoustique usuelle peut être dérivée pour des fluides non isentropiques. Dans un cas particulier où la pression prend une forme spéciale et où les perturbations non adiabatiques sont négligées, les perturbations acoustiques adiabatiques correspondant à des phonons sans masse se propagent dans une métrique analogue du type usuel.
