Dans cet article, je propose un modèle de trou de ver statique en gravité modifiée $f(R,T)$ avec $f(R,T)=R+2λT$. Les solutions de trou de ver ont été développées dans quatre cas : trois fonctions de forme différentes avec le décalage vers le rouge $φ=\frac{φ_0}{r}$, et un paramètre d'équation d'état variable $ω(r)$ avec une fonction de décalage vers le rouge constante. J'ai également exploré les conditions d'énergie et le comportement de la matière exotique dans le trou de ver dans tous les scénarios. La présence de matière exotique viole les conditions d'énergie nécessaires près de la gorge du trou de ver, ce qui impose une contrainte sur le paramètre de gravité modifiée $λ$ dans tous les cas.
