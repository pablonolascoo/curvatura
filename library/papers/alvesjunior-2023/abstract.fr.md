Dans cet article, nous proposons des modèles analogues de branes à base de métamatériaux, fondés sur l'approche de l'optique géométrique. Nous montrons comment modéliser le modèle de brane mince de Randall-Sundrum et le modèle de Gremm pour une brane épaisse. Nous incorporons au système analogue la mécanique de confinement de type Yukawa pour les branes épaisses et présentons un modèle de brane analogue asymétrique avec et sans les mécanismes de confinement.
