Nous considérons la propagation d'ondes gravitationnelles intenses interagissant avec un vide non perturbatif de champs spinoriels. Pour décrire ce dernier, nous proposons un modèle approché. L'équation d'Einstein correspondante a la forme de l'équation de Schrödinger. Sa solution en onde gravitationnelle est analogue à la solution de l'équation de Schrödinger pour un électron se déplaçant dans un potentiel périodique. La solution générale pour les ondes gravitationnelles périodiques est trouvée. L'analogue du modèle de Kronig-Penney pour les ondes gravitationnelles est considéré. Il est montré que le modèle d'ondes gravitationnelles proposé permet l'existence de faibles densités de charge et de courant électriques concomitantes à l'onde gravitationnelle. À partir de cette observation, une possible vérification expérimentale du modèle est suggérée.
