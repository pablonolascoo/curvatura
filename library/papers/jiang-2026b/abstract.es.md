La construcción de un agujero de gusano atravesable estático requiere materia exótica que satisfaga las condiciones de Morris-Thorne. Los tensores energía-momento cuánticos se han considerado durante mucho tiempo el candidato más prometedor para dicha materia exótica. En este artículo presentamos el primer cálculo del tensor energía-momento de un campo escalar masivo cuántico en estados térmicos localizado en la garganta de un agujero de gusano de fuerza de marea nula. Variando la temperatura adimensional y la masa adimensional del campo escalar, encontramos que las condiciones de Morris-Thorne solo pueden satisfacerse cuando la masa del campo escalar se encuentra dentro de un intervalo acotado específico. Además, para cualquier masa del campo escalar dentro de este intervalo, existe siempre una temperatura crítica adimensional dependiente de la masa: las condiciones de Morris-Thorne se cumplen solo si la temperatura permanece por debajo de este umbral crítico.
