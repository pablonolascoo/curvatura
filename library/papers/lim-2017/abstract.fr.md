Nous présentons une solution exacte en gravité d'Einstein-Maxwell-dilaton décrivant un espace-temps avec une singularité anisotrope de type Kasner et une asymptotique de Lifshitz. Cette configuration peut également être soutenue par un scalaire fantôme tout en satisfaisant la condition d'énergie nulle. Pour certains paramètres de cette solution, les géodésiques nulles peuvent avoir un potentiel effectif infiniment profond, piégeant ainsi des photons dans une région finie le long de la direction radiale. Quelques exemples de géodésiques nulles périodiques sont obtenus. Un cas particulier spécialement intéressant de cette solution est une métrique régulière de type soliton qui conserve son échelonnement de Lifshitz dans la coordonnée temporelle.
