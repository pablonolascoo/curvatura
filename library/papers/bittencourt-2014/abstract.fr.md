La propagation de la lumière dans les matériaux non linéaires est ici étudiée dans le régime de l'optique géométrique. Il est montré qu'un milieu à symétrie sphérique au repos, avec certaines propriétés diélectriques spécifiques, peut servir à produire un modèle analogue exact pour une classe d'espaces-temps incluant des solutions de trou noir statiques à symétrie sphérique. Le modèle optique présenté ici peut être un outil utile pour reproduire en laboratoire le comportement des géodésiques nulles optiques près d'un objet compact dont le rayon gravitationnel de Schwarzschild est observable.
