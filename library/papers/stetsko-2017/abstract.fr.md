Pour obtenir des modes quasi normaux fermioniques, l'équation de Dirac est étudiée pour deux types de trous noirs. Pour le premier type de trou noir, les modes quasi normaux ont un spectre continu à partie imaginaire négative, ce qui assure la stabilité de la géométrie du trou noir. Pour le second type de trou noir, les modes quasi normaux ont un spectre discret et sont entièrement imaginaires. Ce type de trou noir semble être stable pour des masses arbitraires des perturbations du champ fermionique.
