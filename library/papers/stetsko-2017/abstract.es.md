Para obtener modos cuasinormales fermiónicos se investiga la ecuación de Dirac para dos tipos de agujeros negros. Para el primer tipo de agujero negro, los modos cuasinormales tienen espectro continuo con parte imaginaria negativa, lo que asegura la estabilidad de la geometría del agujero negro. Para el segundo tipo de agujero negro, los modos cuasinormales tienen espectro discreto y son completamente imaginarios. Este tipo de agujero negro parece ser estable para masas arbitrarias de las perturbaciones del campo fermiónico.
