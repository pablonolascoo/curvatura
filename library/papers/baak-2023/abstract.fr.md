Afin de caractériser de manière invariante la structure de courbure conforme d'espaces-temps analogues construits à partir d'un fond fluide non relativiste, nous déterminons le type de Petrov de diverses géométries de laboratoire. En partant des exemples les plus simples, nous augmentons la complexité du fond et déterminons ainsi comment la symétrie du fluide de laboratoire affecte le type de Petrov correspondant dans le domaine de l'espace-temps analogue des ondes sonores. Nous trouvons que, pour des écoulements plus complexes, des hypersurfaces isolées se développent, dont le type de Petrov diffère de celui du fluide environnant. Enfin, nous démontrons que, dans l'approximation du fond incompressible, ainsi que pour tous les écoulements compressibles quasi unidimensionnels, les seuls types de Petrov possibles sont le type I, algébriquement général, et les types O et D, algébriquement spéciaux.
