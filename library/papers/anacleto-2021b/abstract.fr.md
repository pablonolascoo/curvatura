Un modèle de fluide acoustique non commutatif en expansion, analogue à une géométrie de Friedmann-Robertson-Walker, est établi. Pour cela, un modèle de Higgs abélien non commutatif est considéré dans un espace-temps à (3+1) dimensions. Dans ce scénario, nous analysons le mouvement de particules test dans ce fluide. L'étude considère une particule test scalaire couplée à un champ scalaire sans masse, quantifié et fluctuant. Dans tous les cas étudiés, nous trouvons des corrections dues à la non-commutativité dans la vitesse quadratique moyenne des particules. La dispersion de vitesses non nulle des particules libres de se déplacer le long des géodésiques est en désaccord avec le résultat nul trouvé précédemment dans la littérature pour un fluide commutatif en expansion.
