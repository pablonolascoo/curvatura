This philosophical chapter explores whether dialetheism, the view that true contradictions can exist, solves the grandfather paradox in time travel. On that response, some contradictions would be true when travelling, for example that one's grandfather is both dead and alive in 1930. The option had received little attention and the chapter analyzes it. It concludes that even if one accepts true contradictions, the help is small: one ends with a bizarre theory or one indistinguishable from a theory requiring an indexed world, such as hypertime.
