Les trous de ver (WH) requièrent de l'énergie négative, et donc une source de matière exotique. L'énergie de Casimir étant négative, on a spéculé il y a longtemps qu'elle serait une bonne candidate pour alimenter ces objets. Cependant, ce n'est que très récemment qu'une solution complète pour $D = 4$ a été trouvée par Garattini, de sorte que l'énergie de Casimir peut être la source de WH traversables. Dans le manuscrit publié par les auteurs, nous montrons que cette solution est possible pour tout espace-temps de dimension $D > 3$. Récemment, Garattini a cherché à analyser les effets de termes de type Yukawa sur les fonctions de forme et a obtenu des résultats prometteurs. Il adopte cependant des prémisses raisonnablement discutables en établissant une non-homogénéité dans l'équation d'état, en supposant une fixation entre les constantes qui n'est observée que dans le modèle usuel et en considérant la condition de marée nulle, non observée dans les trous de ver de Casimir. Dans ce travail, nous étudions les effets engendrés par des facteurs correctifs de type Yukawa sur des solutions de trou de ver traversable engendrées par l'énergie de Casimir sans adopter de telles prémisses. Nous observons que, outre la possibilité de construire des trous de ver traversables satisfaisant toutes les conditions nécessaires, il est possible d'obtenir une fixation adéquate des constantes afin de retrouver le cas standard sans double limite. On a observé que, dans les cas global et constant, il est possible de fixer une valeur du paramètre d'écrantage qui fait que le trou de ver engendre une force gravitationnelle répulsive. Enfin, nous avons observé que, dans le cas constant, il existait une limitation du facteur d'écrantage, ce qui n'était pas observé dans l'article original.
