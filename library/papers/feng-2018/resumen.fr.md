Les auteurs construisent une nouvelle solution périodique dans le temps et une solution de type machine à remonter le temps, à partir d'une famille de solutions des équations d'Einstein dans le vide avec constante cosmologique. Les solutions périodiques sont liées à l'univers en boucle. Celles de type machine temporelle sont des configurations à courbes temporelles fermées permettant à un observateur de revenir dans son propre passé. Ils espèrent les voir utilisées en cosmologie et relativité générale, mais les sources ne détaillent pas l'analyse physique.
