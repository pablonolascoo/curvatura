Les électrons dans les semi-métaux de Weyl de type II présentent une propagation unidirectionnelle, ce qui soutient un comportement de réflexion totale à une extrémité, comme pour les horizons de trou noir vus de l'intérieur. Les jonctions de type I et de type II conduisent à des équations identiques à celles que l'on a près des horizons de trou noir, mais les implications physiques, suggérons-nous, sont très différentes des attentes conventionnelles dans ce contexte. La configuration de « trou blanc », renversée dans le temps, est elle aussi physiquement accessible.
