Les conditions d'énergie nulle moyennée (ANEC) énoncent que, le long d'une courbe nulle complète, les fluctuations d'énergie négative d'un champ quantique doivent être équilibrées par des fluctuations d'énergie positive. Nous utilisons la correspondance AdS/CFT pour démontrer l'ANEC pour une classe de théories conformes des champs à fort couplage dans l'espace-temps plat. Une violation de l'ANEC dans la théorie des champs conduirait à une propagation acausale de signaux dans le bulk.
