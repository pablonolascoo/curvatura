On sait que l'énergie gravitationnelle totale dans des sources localisées à symétrie sphérique statique satisfaisant les conditions d'énergie est négative (gravité attractive). Une question naturelle est de savoir comment se comporte l'énergie gravitationnelle dans des circonstances où les conditions d'énergie sont violées. Pour y répondre, l'expression connue de l'énergie gravitationnelle est modifiée de manière appropriée afin de rendre compte de situations comme celles qui se produisent dans l'espace-temps d'un trou de ver. On illustre ensuite que, dans de nombreux cas, l'expression modifiée donne des réponses souhaitables. Les implications sont discutées.
