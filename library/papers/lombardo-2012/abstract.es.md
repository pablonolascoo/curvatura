Estudiamos el proceso de decoherencia inducido por la presencia de un entorno en agujeros negros acústicos, utilizando el enfoque de sistemas cuánticos abiertos, ampliando así trabajos anteriores. Nos centramos en el modelo de trampa de iones, pero el formalismo es general para cualquier implementación experimental. Calculamos el tiempo de decoherencia para esa configuración. Encontramos que durante la medida se produce una transición de cuántico a clásico y propusimos parámetros mejorados para evitar dicha característica. Proporcionamos estimaciones analíticas tanto a temperatura nula como finita. También estudiamos el entrelazamiento entre los fonones del par de Hawking de un agujero negro acústico en contacto con un reservorio, mediante las correlaciones cuánticas, mostrando que permanecen fuertemente correlacionados para tiempos y temperaturas suficientemente pequeños. Utilizamos el formalismo estocástico y el método de las características para resolver la ecuación de ondas del campo.
