Estudiamos el flujo de Ricci-Bourguignon en variedades producto alabeado (warped) con base no compacta. Este marco conduce de forma natural a una ecuación en derivadas parciales parabólica en el espacio de funciones de alabeo suaves, que surge de las condiciones necesarias y suficientes para que una métrica alabeada evolucione bajo el flujo. Uno de nuestros resultados principales establece una estimación de gradiente para esta ecuación, que proporciona el insumo analítico para las aplicaciones geométricas aquí desarrolladas y, en particular, recupera estimaciones de gradiente clásicas para la ecuación del calor bajo el flujo de Ricci. Además, desarrollamos un método para construir soluciones explícitas de producto alabeado del flujo de Ricci-Bourguignon y presentamos ejemplos que ilustran el alcance y la relevancia geométrica de nuestros resultados
