Dos espejos paralelos cercanos se atraen debido a una pequeña fuerza (efecto Casimir) originada por las fluctuaciones cuánticas del vacío electromagnético del campo electromagnético. Estas fluctuaciones del vacío también pueden inducir fuerzas de movimiento ejercidas sobre un espejo cuando el otro se mueve. Aquí consideramos un sistema optomecánico formado por dos espejos vibrantes acoplados a un resonador óptico. Encontramos que las fuerzas de movimiento pueden determinar tasas de acoplamiento apreciables entre los dos espejos vibrantes separados espacialmente. Mostramos que, sintonizando los dos osciladores mecánicos en resonancia, se intercambia energía entre ellos a nivel cuántico. Este acoplamiento de movimiento coherente es posible gracias al intercambio de pares de fotones virtuales, originados por el efecto Casimir dinámico. El proceso propuesto aquí muestra que el vacío cuántico electromagnético es capaz de transferir energía mecánica de forma parecida a un fluido ordinario. Mostramos que este sistema también puede funcionar como conversor paramétrico descendente mecánico incluso con excitaciones muy débiles. Estos resultados demuestran que las fuerzas de movimiento inducidas por el vacío abren nuevas posibilidades para el desarrollo de tecnologías cuánticas optomecánicas.
