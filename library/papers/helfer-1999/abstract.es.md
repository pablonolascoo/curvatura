Para teorías de campos bosónicos lineales, muestro que, si una función hamiltoniana clásica es estrictamente positiva, existe una transformación canónica que hace ortogonal la evolución. Este teorema de estructura se utiliza para analizar las teorías cuánticas correspondientes. Se muestra que existe una conexión íntima entre la acotación inferior y la implementabilidad autoadjunta. Por último, se muestra que existe una amplia clase de "desigualdades cuánticas:" cualquier componente temporal del operador densidad de cuadrimomento, promediada sobre una región compacta del espaciotiempo curvo, debe estar acotada inferiormente.
