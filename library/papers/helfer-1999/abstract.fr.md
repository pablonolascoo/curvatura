Pour les théories de champs bosoniques linéaires, je montre que, si une fonction hamiltonienne classique est strictement positive, il existe une transformation canonique rendant l'évolution orthogonale. Ce théorème de structure est utilisé pour analyser les théories quantiques correspondantes. On montre qu'il existe un lien intime entre le caractère borné inférieurement et l'implémentabilité autoadjointe. Enfin, on montre qu'il existe une large classe d'« inégalités quantiques : » toute composante de genre temps de l'opérateur densité de quadri-impulsion, moyennée sur une région compacte de l'espace-temps courbe, doit être bornée inférieurement.
