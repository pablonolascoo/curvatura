Les électrons des semi-métaux de Weyl de type II présentent une propagation à sens unique, ce qui produit une réflexion totale à une extrémité, comme pour les horizons de trous noirs vus de l'intérieur. Les jonctions entre matériaux de type I et de type II conduisent à des équations identiques à celles proches d'un horizon, mais les auteurs suggèrent que les implications physiques diffèrent beaucoup de ce qu'on attend dans le cadre conventionnel. La configuration renversée dans le temps, un trou blanc, serait elle aussi physiquement accessible dans ces matériaux. C'est un analogue de matière condensée de la physique des horizons.
