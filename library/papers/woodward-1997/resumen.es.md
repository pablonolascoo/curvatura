El artículo repasa brevemente las razones científicas para intentar fabricar agujeros de gusano transitables y examina métodos para hacerlo con una fluctuación transitoria de masa de tipo machiano. Menciona varios problemas que podrían surgir, que según el autor podrían ser solo dificultades de ingeniería. También analiza el uso de las desigualdades cuánticas para limitar la masa-energía negativa necesaria en la formación de agujeros de gusano, y sostiene que estas desigualdades no prohíben crear concentraciones artificiales de masa-energía negativa.
