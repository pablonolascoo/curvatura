Dans le contexte de l'interaction entre le champ électromagnétique et un milieu diélectrique dispersif sans pertes, nous présentons une version non linéaire du modèle de Hopfield relativistement covariant, adaptée à la description d'une perturbation Kerr diélectrique se propageant dans un milieu diélectrique. La non-linéarité est introduite dans le lagrangien par un terme d'auto-interaction proportionnel à la puissance quatre du champ de polarisation. Nous trouvons une solution exacte des équations non linéaires décrivant une perturbation qui se propage dans le milieu diélectrique. De plus, la présence d'un effet Hawking analogue ainsi que les propriétés thermiques du modèle sont discutées, ce qui confirme et améliore les résultats obtenus dans le cas scalaire.
