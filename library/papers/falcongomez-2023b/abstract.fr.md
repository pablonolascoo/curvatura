Nous étudions l'interaction entre des ondes planes gravitationnelles et électromagnétiques au moyen d'un modèle électromagnétique analogue de la gravité, dans lequel les propriétés gravitationnelles sont codées dans les propriétés électromagnétiques d'un matériau dans un espace-temps plat. Dans ce dispositif, les variations du tenseur métrique produites par les ondes gravitationnelles sont codées sous forme de propriétés électromagnétiques variant dans l'espace-temps. Nous avons utilisé un code maison fondé sur la méthode des différences finies dans le domaine temporel pour mener des expériences numériques, dans lesquelles nous avons trouvé que, lorsqu'une onde plane gravitationnelle monochromatique interagit avec une onde plane électromagnétique à bande étroite, un nombre infini de bandes latérales, également espacées entre elles, sont induites par l'onde gravitationnelle. Enfin, nous discutons d'éventuelles applications futures de cet effet comme méthode alternative pour détecter directement les ondes gravitationnelles.
