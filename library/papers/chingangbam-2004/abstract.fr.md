Nous étudions les conséquences inflationnaires du champ scalaire massif roulant dans le scénario de monde-brane avec une métrique gauchie (warped). Nous trouvons que, pour satisfaire les contraintes observationnelles, le facteur de gauchissement doit être ajusté à $< 10^{-3}$. Nous démontrons aussi le comportement d'attracteur inflationnaire de la dynamique du champ scalaire massif, tant dans le cas FRW standard que dans le scénario de monde-brane.
