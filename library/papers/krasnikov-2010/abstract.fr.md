Je montre qu'il existe une lacune importante dans la démonstration du théorème connu sous le nom de « censure topologique » (un théorème interdisant à une solution des équations d'Einstein de présenter certaines caractéristiques topologiques, comme des trous de ver traversables, sans violer la condition d'énergie nulle moyennée). Pour combler cette lacune, il faudrait probablement réviser la classe d'espaces-temps pour laquelle le théorème est formulé.
