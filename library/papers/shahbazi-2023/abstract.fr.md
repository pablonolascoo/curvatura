La confirmation empirique dans certains domaines de la physique est obscure ; par exemple pour le rayonnement de Hawking. Cependant, la gravité analogue peut simuler ces phénomènes dans des systèmes de matière condensée. C'est une question importante de savoir si l'observation de ces phénomènes dans les systèmes de matière condensée peut ou non confirmer le phénomène original. Dans ce travail, nous répondons affirmativement à cette question au moyen du structuralisme.
