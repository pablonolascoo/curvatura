Calculamos la energía de Casimir de una región esférica usando un enfoque de impedancia superficial. Caracterizamos la impedancia superficial de la frontera mediante el modelo de plasma. Se obtienen fórmulas analíticas exactas mediante el método de regularización por función zeta y se calculan explícitamente todas las divergencias. Encontramos que es posible tener energía de Casimir negativa para cierto rango de valores del parámetro relevante. Se discuten los límites de aplicabilidad del modelo.
