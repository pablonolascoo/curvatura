Récemment, de nombreux physiciens suggèrent que l'énergie sombre de l'univers pourrait provenir du champ scalaire de type Born-Infeld (B-I) de la théorie des cordes. L'univers avec un champ scalaire de type B-I avec potentiel peut traverser une phase d'expansion accélérée. Le paramètre de l'équation d'état correspondant se situe dans l'intervalle $\displaystyle -1<ω<-{1/3}$. Le paramètre de l'équation d'état du champ scalaire de type B-I sans potentiel se situe dans l'intervalle $0\leqω\leq1$. Nous trouvons que la condition d'énergie faible et la condition d'énergie forte sont violées pour le champ scalaire fantôme de type B-I. Le paramètre de l'équation d'état se situe dans l'intervalle $ω<-1$.
